# Zad marketing site

Next.js 16 · Tailwind CSS 4 · React Three Fiber + drei · Motion · Lenis. Arabic, RTL, dark.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Store links live in `lib/links.ts`. Set `APP_STORE_URL` once the iOS app is published and the
"قريباً" badge turns into a real App Store button.

## Deploy on Vercel

Import the repo in Vercel and set **Root Directory = `website`**. The framework preset
(Next.js) is detected; no environment variables are needed.
